## Intent

**Problem:** OcuPilot has nothing for the classic Archive Manager page (`EnsPortal.ArchiveManager`), so a namespace's archive settings cannot be read or kept, its last run's errors cannot be read, and old messages cannot be archived into another namespace; nothing round-trips over `Ens.Archive.Manager`. The story's README clauses, owed by every batch, and DW-2856 (the export consequence's wording) are also open.

**Approach:** Batch 4 of four (Batch 1's veto item 1): three screens through `InteropPort` — **Archive manager** (the last run's history, and Run archive), **Archive settings** (target namespace and days, each set by itself; the archive class shown, never set) and **Archive errors** — with two writes, each one operation reached by the screen and by the agent, extending Batch 1's purge family. "Round-trips" means: a setting set from either caller reads back through `Ens.Archive.Manager.GetArchiveParameters` as sent; a run from either caller leaves each message older than the days saved in the target under its own id with its body as text, gone from the namespace, and the history and error list read that run. Then the README clauses and DW-2856.

## Boundaries & Constraints

**Always:**

- **One port (AD-62), the purge family extended (Rule 31).** `InteropPort` gains `ArchiveSettings` (`LIST`, `SETTING`, `SETTINGSET`), `Archive` (`LIST`, `ARCHIVESTATE`, the write `ARCHIVE`) and `ArchiveErrors` (`LIST`, the vendor's `Ens.Archive.Manager:Errors` query, capped and truncation reported, AD-36). Switched by save and restore; no `OcuPilot.*` call while switched, logging included; a fault is logged after the restore.
- **Rows.** Settings `{Name, Value, Stored, Kind, Accepts, ReadOnly, Namespace}`, the classic captions in the classic order: Archive to namespace (`choice`, Accepts the list below), Archive manager class name (`ReadOnly` true, Accepts `ConfigError.ACCEPTSREADONLY`), Number of days before archiving (`integer` 0 to `ARCHIVEMAXDAYS` 36500); an unset one reads the vendor default (`""`, `Ens.Archive.Manager`, 30) with `Stored` false. History `{Name, Value, Namespace}`, the classic page's eight rows (`DrawStatus` :427-442) from the vendor getters. Errors `{ErrorNumber, Time, Description, MessageId}` as the query answers them. `ARCHIVESTATE` `{Target, Classname, DaysToArchive, Running, Total, ToArchive, Namespace}`.
- **The target list** is the classic page's: `^%SYS("Ensemble","InstalledNamespace")` minus the namespace itself (`EnsPortal.ArchiveManager` :147-160), read at the call; when it is empty the row's Accepts reads Veto items 1's empty-list sentence and every value is refused.
- **Gate (AD-29, AD-8), before any vendor call or value judged; never cached.** Every read: `%Ens_Portal:USE`, `%Ens_ArchiveManager:READ` (the classic `RESOURCE`, :13), then `Admit`. Settings set: plus `%Ens_ArchiveManager:WRITE` (`EDITRESOURCE` :16, `GetHyperEventResources` :552-559) and WRITE on the namespace's globals database. Run: the same, then, at the write after the target is read and before any vendor call, WRITE on the **target's** globals database (and READ there if Task 0 (f) measures it), refused 403 naming the pair, plus any pair Task 0 (f) measures.
- **Which databases a run writes.** The namespace's globals database (each moved message's header and body deleted; the vendor's run history `^Ens.ArchiveManager("run")` replaced) and the target's (each header saved under its own id in `^Ens.MessageHeaderD`, each body as an `Ens.Archive.MessageBody` in `^Ens.Archive.MessageBodyD`). Both map to each namespace's own database (measured at plan, Design Notes).
- **The run, in order, all before the vendor call.** In the proposal's namespace: take `^Ens.ArchiveManager("lock")` at once (`:0`), else 409 `INTEROP.ARCHIVE.RUNNING` (a refusal, never a wait); a stored class other than `Ens.Archive.Manager` is 409 `INTEROP.ARCHIVE.CLASS`; a target unset or not in the list is 409 `INTEROP.ARCHIVE.NOTARGET`; more than `ARCHIVEMAXMESSAGES` headers in the namespace is 409 `INTEROP.ARCHIVE.TOOMANY`; the target's pairs; a target already holding a header id the run would archive (`TimeCreated` before `Ens.Purge.GetDoNotDeleteDate(days)`, the vendor's own rule) is 409 `INTEROP.ARCHIVE.TAKEN`. Then `##class(Ens.Archive.Manager).DoArchive()` while the port holds the lock (the vendor's `lock +...:1` is re-entrant in the process), with no transaction; the lock is let go on every exit.
- **The bound (named limit).** `ARCHIVEMAXMESSAGES` (provisional 10,000; Task 0 (h) sets it) caps the namespace's whole header count, because the vendor's run opens every header and body of the namespace; refused whole above it, boundary-tested at the cap and one over (a seam lowers the cap). A run that still outlasts the Web Gateway's response timeout (60 s, measured) runs to its end in that process, its answer is lost, and its audit row is written when the vendor call returns.
- **A partial outcome follows the purge (orchestrator ruling: a single operation).** A run whose vendor status is an error, or that leaves any entry in the vendor's error log, answers 500 `INTERNAL` ("An internal error occurred"), never 200; its audit row carries `completed` false; the error list names each message.
- **Writes (AD-3, AD-6, AD-10, AD-14, AD-22, AD-34, AD-51, AD-53, AD-56, AD-58, AD-59).** `interop.archivesettings.set` extends `ConfigSettingSet` as `InteropPurgeSettingSet` does; it calls `SetArchiveParameters` with the other two values read at the write (the classic Save's call); a `ReadOnly` row is 409 `CONFIG.SETTING.READONLY`; a value outside its kind 400 `CONFIG.SETTING.VALUE`; an unknown name 404 `CONFIG.SETTING.NOTFOUND`; read-back compares `Value`; key `true`. `interop.archive.run` is action-style with no declared value, `DRYRUN`, `DESTRUCTIVE`, `FINGERPRINTSUBJECT` `Target,DaysToArchive,Classname,Namespace,Running`, precondition field `Running`, key `false`; the screen's Run archive types the namespace's name. A script form per tool that shape-checks every value, renders nothing when one fails, and renders the switch, each refusal as a one-line guard, the lock and the vendor call, running none. A screen action mints nothing and is not gated by read-only or the kill switch.
- **Rosters.** Both tools are classified in `ConfirmNamespaceRoster` and `DraftRegistry` (each run green with them, red with a row removed); every other pinned roster is in the Code Map; the two entity types go after feature's last entries in `TYPES` and `COVEREDTYPES`.
- **Namespace at confirm (AD-52).** Both stored proposals carry `Namespace`; every confirm-time judgment (the fresh read, the target list, the lock, the class, the cap, the taken ids, the vendor call) runs in the proposal's namespace, whichever namespace the confirm is sent from.
- **Audit (AD-15).** The agent's marker on every agent write; OcuPilot's own `ConfigChange` from either caller through `AuditRuntime`: a set names the namespace, the setting and the value; a run names the namespace, the target, the days, the vendor's five counts and `completed`, written after the restore whatever the vendor answered.
- **DW-2856.** The export consequence (`MESSAGEEXPORT`) reads exactly: "Exporting saves the body of each message marked to be exported to one file in this browser's downloads, in message id order, each marked off by the chosen separator. Each body exported is recorded in the audit log as viewed.
