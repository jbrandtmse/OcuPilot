## Intent

**Problem:** The classic locale page's Copy and Load table actions (`%CSP.UI.Portal.NLS`) and its properties editor (`%CSP.UI.Portal.NLSEdit`: seven groups, I/O table add and remove, custom `y` locales only) have no route, screen or tool in OcuPilot, so an operator who wants a custom locale, or a table loaded, has to use the classic portal.

**Approach:** Extend Story 21.14's `LocalePort` with a `Properties` endpoint: one row per property, table and I/O table of one locale, read as a sub-resource of the Locale definitions list. Five writes, each reached by a person's action and a confirmed agent proposal (AD-53): Copy (a create, AD-54), Set value (one property, AD-4 merge), Add table and Remove table (one list member, AD-56 (ii) delta), and Load table (destructive, key off).

## Boundaries & Constraints

**Always:** `LocalePort` is the only product class that calls `Config.NLS.Locales.Create`, `.Modify`, `Config.NLS.Tables.Load` or the `Config.NLS.Tables:List` and `Config.NLS.Locales:Tables` queries; it gates before any vendor call (AD-29) and switches namespace by save and restore (AD-16). Set, Add and Remove change only a custom (`y`) locale that is not current; every other locale is refused from either caller, at the mint, the screen action and the port under the per-target lock. Every write sends the complete settable set as the fresh read holds it with the one change applied (AD-4). A locale, a list, a table, a table type and an I/O table are each checked against the instance's own lists, compared exactly, before any vendor call; no caller value reaches a query pattern (AD-21). Every read is bounded (AD-36). Load table is destructive and its key ships `false`.

**Never:** No edit of a shipped or the current locale, no copy over an existing locale, no change to an existing I/O table's sides (remove and add it), no Accent table load, no harvested body, no user-facing string beyond those the spec gate rules. OcuPilot's own interface stays English.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|---|---|---|---|
| Properties read | `locale` criterion `enuw` | One row per editable or shown property, per table each list holds, per I/O table: `{Locale, Group, Name, Value, Kind, Accepts, ReadOnly, Refusal, Loadable}` | unlisted locale: 404 `LOCALE.NOTFOUND`; no criterion: refused as a missing required criterion (AD-36) |
| Copy | target `yenw`, `Source` a listed locale, optional `Description` | listed, `Custom`; its `Get` equals the source's but `Name` and `Description` | 400 `LOCALE.COPY.NAME`; 409 `LOCALE.COPY.TAKEN`; 404 `LOCALE.NOTFOUND` for `Source` |
| Set value | row `[y…w, DateFormat]`, `Value` 3 | `Get` answers 3, every other property unchanged, `readBack` matches | 400 `CONFIG.SETTING.VALUE`; 409 `CONFIG.SETTING.READONLY`, `LOCALE.EDIT.SYSTEM`, `LOCALE.EDIT.CURRENT` |
| Add table | target `[y…w, PatternTables:Latin2]`; or `XLTTables:<name>` with `InputFrom`, `OutputTo` | listed in that list (I/O: `$LB(InputFrom, cs, cs, OutputTo)`); other lists unchanged | 409 `LOCALE.TABLE.UNAVAILABLE`, `LOCALE.TABLE.TAKEN`, the two `EDIT` codes; 400 `PORT.VALIDATION` for I/O sides on another list or missing on `XLTTables` |
| Remove table | a member row | gone; read-back expects 404 | 409 `LOCALE.TABLE.DEFAULT` for the type's default (or an I/O default's table), `LOCALE.TABLE.ROW` for a non-table row, the two `EDIT` codes |
| Load table | a `Loadable` row, key `true` | `Config.NLS.Tables.Load(locale, type, table)` answers OK; `readBack` `nothingSent` | 409 `LOCALE.TABLE.NOTLOADABLE`; default baseline: governance refusal, both callers |

**Acceptance Criteria:**

- AC1. Given a locale on `ocupilot-ci`, when its properties are read by the screen and the tool, then every row equals `Config.NLS.Locales.Get` and its `Tables` query, and when a person and the agent each copy it to a new `y` name, then each round-trips over `Create` (listed, `Get` equal but `Name` and `Description`, `readBack` matches); a taken name is refused `LOCALE.COPY.TAKEN` before any vendor call.
- AC2. Given a copy, when Set value, Add table and Remove table run by both callers on scalars, an internal list and the I/O tables, then each round-trips over `Modify` with every other property unchanged and `readBack` matching, and removing a type's default is refused `LOCALE.TABLE.DEFAULT` before any vendor call.
- AC3. Given a shipped locale and the current locale, when either caller sets, adds or removes, then it is refused `LOCALE.EDIT.SYSTEM` or `LOCALE.EDIT.CURRENT` before any vendor call, and the screen draws each action unavailable with that sentence.
- AC4. Given Load table's key `true` and a copy's loadable table, when a person and the agent load it, then `Config.NLS.Tables.Load` runs with that locale, type and table; with the default baseline governance refuses the agent's; a non-loadable row is refused `LOCALE.TABLE.NOTLOADABLE` before any vendor call.
- AC5. Given these configure the server's locales rather than OcuPilot's own interface, when the properties screen, both dialogs and the cards render, then every label, group word, refusal and consequence is an English `strings.ts` value pinned equal to its `LocaleError` or `ConfigError` sentence.

**Self-protection.** Set, Add and Remove are refused from either caller, at the mint, the screen action and the port, for a shipped locale (an upgrade restores it) and for the current locale (every process, OcuPilot's included, takes its formats and tables from it), as 21.14 refuses deleting either; stricter than the classic editor, which edits a current `y` locale. Copy cannot copy over anything: its target must be absent (AD-54) and named `y`. Load table on the current locale is destructive with its key off, from either caller: `Load` "changes defaults if necessary", and that can change how OcuPilot's processes translate data (inference); if Task 0 (c) shows it changes a `System` default, the port refuses it on the current locale with `LOCALE.EDIT.CURRENT`. Loading from another locale adds a table to the running instance without changing a default (inference, Task 0 (c)).

**Decided in-stage:**

- One properties list per locale, rows for properties, tables and I/O tables, served by the config settings page: the set dialog, `Accepts` and `CONFIG.SETTING.*` sentences are reused. The seven groups are a `Group` column, not seven forms.
