## Intent

**Problem:** The instance's NLS configured defaults (classic `NLSConfigDefs`) and its locale definitions (classic `NLS`) have no screen, no route and no tool in OcuPilot. An operator who wants to see which tables the instance defaults to, or to validate, install or delete a locale, has to use the classic portal.

**Approach:** Add an `NLSDefaults` endpoint to Story 21.3's `ConfigPort` (every table row read-only; the one settable row is the locale-format switch), and a new `LocalePort`, on `BackupPort`'s shape, for the locale list and its actions: Validate (a read), Install and Delete. Each write is reached by a person's action and a confirmed agent proposal (AD-53). Copy, the properties editor and Load table are Story 21.16's.

## Boundaries & Constraints

**Always:** `ConfigPort` and `LocalePort` are the only product classes that name `%SYS.NLS.Table`, `Config.NLS.Locales` or `^SYS("NLS","Config")`; each gates before any vendor call (AD-29) and switches namespace by save and restore (AD-16). Every write is minted, confirmed once, audited, read back (AD-58) and announced (AD-14). A locale is checked against the instance's own list, compared exactly, before any vendor call, and no caller value reaches the `List` query's pattern (AD-21). Every read is bounded (AD-36). Install and Delete are destructive and their keys ship `false`.

**Never:** No configured-default table is settable (the classic page sets none). No Copy, properties edit or Load table (Story 21.16), no Export or Import (Design Notes, Export). No harvested body: the MCP suite's only locale code is a read of the current locale and the locale names (`ExecuteMCPv2.REST.SystemConfig:173-205`). No user-facing string beyond those the spec gate rules. OcuPilot's own interface stays English.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|---|---|---|---|
| Defaults read | `GET` NLS defaults | One row per `%SYS.NLS.Table` category (19) plus `LocaleFormat`; `Value` the effective table, `Source` `config` or `locale`; table rows `ReadOnly` | none |
| Locale-format set | `LocaleFormat` 1, by both callers, then restored | `^SYS("NLS","Config","LocaleFormat")` reads 1, the current locale is reloaded, `readBack` matches | a table row: 400 `CONFIG.SETTING.READONLY` |
| Locales read | `GET` locales | One row per `Config.NLS.Locales:List` entry (36 on slot A): `Name`, `Description`, `Current`, `Custom` (name starts `y`) | none |
| Validate | a listed locale | `{Name, Valid, Installable, Errors[], Warnings[]}` from `IsValid`, `IsLoadable` and `IsInstallable`; nothing written; the lines reach the screen only, the agent's read answers their counts | 404 `LOCALE.NOTFOUND` for an unlisted name |
| Install | a listed locale, key `true` | it becomes current; the answer names the IRISTEMP default collation before and after | 409 `LOCALE.NOTINSTALLABLE` when `IsInstallable` refuses (its lines are Validate's) |
| Delete | a custom, non-current locale, key `true` | it is gone; read-back reads 404 | 409 `LOCALE.SYSTEM` for a system locale, 409 `LOCALE.CURRENT` for the current one |
