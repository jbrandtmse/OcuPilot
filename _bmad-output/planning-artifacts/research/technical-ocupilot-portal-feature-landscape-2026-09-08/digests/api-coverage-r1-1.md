# Official REST API coverage — round 1 — 2026-09-08

Sources consulted: 56 — 33 dispatch-class files under `irissys/%Api/`, 11 pages of the `irisdocs/` mirror (index + 9 guides + 1 classref), the running `ocupilot-iris` instance (IRIS for Health 2026.2 build 221U: 3 MCP admin/dev lookups, 6 `iris_execute_command` probes in `%SYS`, 4 batched `curl` probes), 1 Documatic page and 1 community post fetched from the web, 2 web searches restricted to InterSystems domains.

Notation. **Documented** = has a guide page in the docs mirror. **Hidden** = dispatch class is `[ Hidden ]` on the instance and absent from both the `%SYS` export and the docs index; verified only from the instance. Instance facts are labelled *(instance)*; file-derived facts cite the path.

Headline. Beyond the six documented services (`/api/atelier`, `/api/monitor`, `/api/mgmnt`, `/api/docdb`, `/api/deepsee`, `/api/iam`) and the undocumented-but-public `/api/interop-editors`, this instance ships a **hidden `/api/admin` system-management REST API (`%Api.Admin`, dispatch v1 and v2, 84 classes)** that covers namespaces, databases, security (users/roles/resources/services/web apps/SSL/X.509/OAuth2/LDAP/audit/encryption/SQL privileges), processes, locks, journal, tasks, license, ECP, devices and dashboards — all answering HTTP 200 to Basic auth as `_SYSTEM` today. It is undocumented and hidden, so it must be treated as an unsupported dependency, but it changes the "custom backend unavoidable" list dramatically.

**`POST /:namespace/action/query` — what it does** (`irissys/%Api/Atelier/v1.cls` 638–740):
- Body `{"query": "<SQL>", "parameters": [..]}`; the docstring example is `call %studio.debugger_processlist()`. Content-Type must be `application/json` (415 otherwise); empty/invalid JSON → 400.
- Implementation: `%SQL.Statement.%Prepare(tQuery.query, 0)` then `%Execute(tParams...)`. `SQLCODE < 0` raises → HTTP 500 with the error in `status.errors`.
- Only `%StatementType = 1` (SELECT) and `45` (CALL, iterating `%NextResult()`) are rendered into `result.content`. **There is no statement-type guard before execution** — any other statement type (DML/DDL) is executed by `%Execute` and simply returns empty `content`. No row-limit parameter exists in this method (the `?max=` parameter belongs to `Search`, GSCF_ref.md 1345). Output written during execution is captured into `console`.
- GSCF_ref.md 1248–1310 documents only the SELECT case and says "The query must specify a database in the specified namespace."

### `%Api.Admin` — HIDDEN system-management API (web app `/api/admin`) *(instance only)*

Not in `irissys/%Api/` (hidden classes are omitted from the Atelier document list) and not in `irisdocs/README.md`; two InterSystems-domain web searches found no page for `%Api.Admin`/`/api/admin`. Facts below come from `%Dictionary` on the instance.

- Web app: `%SYS`, dispatch `%Api.Admin`, description "Admin REST Apis", enabled, AutheEnabled=32 (password), `JWTAuthEnabled=1`, `GroupById=%ISCMgtPortal`, `Resource=""`, `CookiePath=/api/admin/`, `CSRFToken=0`.
- `%Api.Admin` extends `%CSP.REST`; parameters `UseSession=0`, `CONVERTINPUTSTREAM=1`, `HandleCorsRequest=1`. UrlMap: GET `/info`; `/v1` → `%Api.Admin.Dispatch.v1`; `/v2` → `%Api.Admin.Dispatch.v2` (v2 extends v1). `AccessCheck()` sets `pAuthorized=1` unconditionally ("relying on the user and application to be defined with appropriate resources"); per-endpoint authorization is `%Api.Admin.Endpoint.ResourcesOR()` (a `$LISTBUILD` of `%Admin_*` resources, any one with `U` suffices).
- `GET /api/admin/info` (live, Basic auth): `apiVersion 2`, username, `serverVersion`, `product "irisforhealth"`, namespace list, and a `privileges` map computed by `$SYSTEM.Security.Check("%Admin_"_r,"U")` over `ExternalLanguageServerEdit, Journal, Manage, OAuth2_Client, OAuth2_Registration, OAuth2_Server, Operate, Secure, Task, Wallet, FileSystemAccess`; 403 if none held. Unauthenticated → 401.
- Envelope: `{"status":{"errors":[],"summary":""},"console":[],"result":…}` (same shape as Atelier). Item selection is by query parameter, e.g. `GET /v2/namespace?name=HSCUSTOM` → `{"Globals":"HSCUSTOM","Routines":"HSCUSTOM","TempGlobals":"IRISTEMP"}`. Long operations return an async handle (`/async-result[s]`, `/async-result/cancel|pause|resume`; endpoints override `ShouldRunAsync()` — e.g. database `info`, namespace `enable-interop`/`copy-mappings`, journal `integrity-check`).

Sharing a session between a custom Angular web app and `/api/atelier`: GSA_manage_applications.md 861–867 — the Session Cookie Path "is the portion of the URL that the browser uses to send the session cookie back … The application only sends the cookie for pages within the specified scope. If you restrict the scope to pages required by a single web application, this prevents other web applications on this machine from using this session cookie", and "a primary application and its subapplications can have different security settings while simultaneously sharing a session cookie (if they all use the primary application's path)." Consequently a custom app can share `/api/atelier`'s CSP session only if both apps' `CookiePath` (Session Cookie Path) is set to a common prefix; with the defaults observed (`/api/atelier/`, `/api/admin/`, …, SameSite Strict) each app's session cookie is isolated. ## Leads — contradictions, newer APIs hinted at, open questions

1. **Docs vs instance on `GroupById`.** GSA_manage_applications.md (line 793) says "Do not use … migrated legacy applications only", yet the shipped 2026.2 Angular surface (`/csp/sys`, `/ui/interop`, `/api/interop-editors`, `/api/admin`) all carry `GroupById=%ISCMgtPortal`, and Documatic describes it as synchronized authentication across a group. Decide whether OcuPilot joins `%ISCMgtPortal` (inherits portal login) or runs its own group/cookie path.
2. **Session cookie → JWT handoff.** `/api/admin` and `/api/interop-editors` have `JWTAuthEnabled=1` and `UseSession=0`; the v7 spec exposes `/%SYS/session/*`. How the Angular bundles in `/ui/interop` obtain the token was not established from primary sources (only a 2025 community post). Next round: read `irisui/_analysis/inventory.json` endpoints for `/ui/interop` (out of this brief's grant) or trace a browser login.
3. **`/api/admin` is the de-facto "System Management REST API"** InterSystems is building for its own new portal (`NormalizeLocationHeader` rewrites to `/iris/api/admin/v1/…`, suggesting a `/iris` front-end prefix). It is hidden and unversioned in docs; v2 already extends v1 with databases/ECP/journal/locks/namespaces/FS-access. Risk: silent change across releases. Mitigation: pin to `/v2`, verify via `GET /info` `apiVersion`, and keep the auto-generated spec from `GET /api/mgmnt/v1/%25SYS/spec/api/admin` under test.
4. **`/api/mgmnt/v2` hides the InteropEditors spec** on purpose; the docs mirror README's statement that the spec can be pulled live at `/api/mgmnt/v2/%25SYS/%25Api.InteropEditors.v7` is wrong for this build — use `irissys/%Api/InteropEditors/v7/spec.cls` (or Documatic) instead.
5. **Atelier `action/query` is an unguarded SQL executor** under the caller's privileges; if OcuPilot exposes it to an agent, the DML/DDL guard has to live in OcuPilot.
6. **Semantics of `/{ns}/productions/{class}/{hostName}/{action}` (UpdateProduction) and `/productions/production/state/{class}`** — which `{action}` values (start/stop/update/recover?) are accepted was not read this run; check `%Api.InteropEditors.v7.impl` / v6.impl.
7. **X.509 backing class**: `Security.X509Credentials` is absent on this instance although `/api/admin` has an X509 endpoint; identify the real class before writing custom code.
8. **HealthShare-specific REST** (`HS.HC.Security.API.*`, `/api/security-config`, `/ui/security-config`, `/csp/oauth2-client/api`) appears in the `/api/mgmnt` lists — a possible official surface for OAuth2/credentials on IRIS for Health, outside this brief.
