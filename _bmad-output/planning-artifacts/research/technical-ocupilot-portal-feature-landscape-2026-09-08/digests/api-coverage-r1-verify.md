## New information

- **`/api/admin` has no web-app-level authorization gate.** `MatchRoles=""` and `Resource=""` on the application (both from `Security.Applications.Get` and `iris_webapp_get`). Authorization is evidently enforced per endpoint against the privilege set the `info` call reports: `ExternalLanguageServerEdit`, `Journal`, `Manage`, `OAuth2_Client`, `OAuth2_Registration`, `OAuth2_Server`, `Operate`, `Secure`, `Task`, `Wallet`, `FileSystemAccess` (each `{"use":true}` for `_SYSTEM`). Any authenticated user can reach the dispatcher; what they can do depends on those privileges.
- **`/api/admin/info` also returns `username`, `serverVersion` and `systemMode`** — useful for an instance-identity check (the two containers are distinguishable by `namespaces`, not by `serverVersion`).
- **Endpoint surface visible from the class list (all Hidden):** `%Api.Admin.Endpoints.*` covers Database (Actions, ConfigCRUD, SysCRUD, async integrity/background tasks), Device (Settings, Standard, SubType), DocDB, ECP (AppServerList, AppServerSSLConnection, DataServer, Settings), FSAccess (Path, Purpose), Journal (File, ListTask, Record, Settings), LanguageServer, License (Key, Server), Lock, Monitor, Namespace (Namespace + Global/Package/Routine mappings), Process, Security (Audit Enabled/Event/Record(+ListTask), Encryption AdminInFile/File/Key/KeyInFile/Settings, LDAP, MFT, OAuth2 Client/ServerDefinition/ResourceServer(+Mapping)/Server/ServerClients, PrivilegedRoutine, Resource, Role, SQLPrivilege Admin/Column/Standard, SSLConfig, Service, Superserver, User, WebAuth, X509Credential), Task (CRUD, Manager), WQMCategory, Wallet (Collection, Secret), WebApp (App, PctClassAccess), WebSession. Support classes: `%Api.Admin.Endpoint`, `%Api.Admin.Endpoints.AsyncResult`, `%Api.Admin.Util.{AsyncTask,AsyncTaskEndpoint,AsyncTaskEndpointQueryParameters,AsyncTaskList,AsyncTaskListResultRows,ClassQuery,General,RequestValidator}` — i.e. there is a first-class async-task pattern (`AsyncResult`, `*ListTask`, `*ListTaskResultRows`) for long-running operations.
- **`/api/atelier` is gated by resource `%Development`.** Combined with C6, any principal holding `%Development:Use` can run arbitrary SQL (including DML/DDL, subject only to SQL privileges) in any namespace via `POST /api/atelier/v1/:ns/action/query`. The claims did not mention the resource.
- **`/api/interop-editors` grants `:%EnsRole_InteropEditorsAPI` via MatchRoles**, and `/api/mgmnt` dispatches to `%Api.Mgmnt.v2.disp` (not `%Api.Mgmnt`).
- **Second container (port 52773) namespaces:** `%SYS, DATAFACTORY, HSCUSTOM, HSLIB, HSSYS, HSSYSLOCALTEMP, SANDBOX1, USER` — the `DATAFACTORY` and `SANDBOX1` namespaces are the definitive tell that a call landed on the wrong instance.
- **Live-instance numbers at probe time (ocupilot):** 7 namespaces incl. `%ALL`, 18 tasks, 10 users, 13 databases, 27 processes.
