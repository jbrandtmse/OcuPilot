## InterSystems' own portal direction

- InterSystems is shipping a "new user interface" for interoperability as an **opt-in** experience. Search extract of the 2026.1 release notes (docs URL below, extract dated 2026-08-30): "The following enhancements are included in interoperability-enabled products in the new user interface (which remains an opt-in experience)." Items listed: Production Configuration (host-specific toolbar, connection-line toggles, change host class from the toolbar, same-name host grouping, global filtering in the Collections panel, File Path Directory selector, copy host name, "Improved UI performance for larger productions, such as those with more than 2,000 hosts", localization, collapsible production items); "New Message Viewer and Message Search included in Production Configuration workflow" with search history; "The new BPL Editor user interface is now embedded in VS Code"; Rule Editor enhancements (30-minute activity timeout). Confidence Medium: the URL is the primary release-notes page, but my direct fetch returned only the navigation shell ("New in InterSystems IRIS 2026.1 | InterSystems IRIS Release Notes", current version 2026.2), so the text is from a search-engine extract. https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCRN_new20261
- Corroboration from an InterSystems staff author: the Management Portal tag listing shows Tani Frankel's "2026.1 Highlight - New UI Message Viewer, Message Search and Visual Trace" and "2026.1 Highlight - New UI BPL Editor" (both 2026-03-15), gist "Modernized interoperability UI features launching in 2026.1 Developer Preview". Confidence High that the posts exist with those titles/dates; contents not read. https://community.intersystems.com/tags/management-portal
- 2026.2 adds a read-only Schema Viewer to the opt-in UI, and "All other Interoperability screens remain in the Standard user interface"; "Existing users can switch between the modernized and standard experiences." Confidence Low (search extracts of community pages with unstable URLs and inconsistent dates). https://community.intersystems.com/tags/interoperability
- **No evidence found this run that any System Administration area — security, users/roles, OAuth/x509, tasks, OS/process views, logs — has moved to the new UI.** Every modernized surface identified is an interoperability surface. The contest brief targets exactly the non-modernized areas and asks for GUIs "powered by InterSystems IRIS management APIs", which is consistent with (not proof of) InterSystems seeding community work where its own roadmap has not yet landed. Inference flagged as such.
- Zen, the framework under the classic portal, is deprecated; a community question (2025-10-30, search extract) states "With Intersystems indicating ZEN pages are being deprecated, I'm looking to find out how to add custom configuration pages for the management portal using the new method similar to the new Rules editor."
