## Leads

- **Live-portal confirmation not performed.** Every row above is source-derived; the rendered menu, the exact header layout and the Analytics category label (`$$$PRODUCT1`) on the running `ocupilot` instance should be confirmed in a later round (2 calls to `list_pages`, then navigate + snapshot of `http://localhost:52774/csp/sys/%25CSP.Portal.Home.zen`).
- **Product names are macros.** `$$$PRODUCT1` (Analytics), `$$$PRODUCT2` (Interoperability), `$$$PRODUCT5` (Text Analytics) come from `%products.inc`; the exported captions therefore differ by edition. Open question: what these resolve to on IRIS for Health 2026.2.
- **`CanShowSwitch(pageName)`** in `%ZEN.Portal.Application` decides whether the namespace link is clickable per page; its rule set was not read. Relevant to the shell's namespace selector design.
- **Auto-logout timer.** `standardPage.onlogoutHandler` documents "the logout timer for this page" but the timer (session timeout → client redirect) is implemented in the Zen page base (`%ZEN.Component.page` / `%CSP.Session` AppTimeout), not in the granted folders. Confirm whether the replacement must mirror a client-side countdown or only server session expiry.
- **Delete semantics for classes.** `ClassList.Delete(filetype)` was identified but its body was not read; expected to call `$System.OBJ.Delete` — unverified.
- **Custom resources** (`%CSP.Portal.Utils.%SetCustomResource`) are keyed by normalised page URL. An Angular portal with different routes must map its routes back to these keys or lose existing custom-resource assignments.
- **Explorer in `%SYS`.** All Explorer items are disabled in `%SYS`/implied namespaces without `%DB_IRISSYS` R/W (`GetSystemExplorerArray`). This is a namespace-scoped gate the replacement must replicate.
- **Dead code.** The Visual Reporting sub-menu and the MDX Query Tool's Open/Save commands are commented out; several `hidden="true"` items exist in SQL Home (Run Script) and QButtons (View Process, Copy). Parity scope should exclude them.
- **Contradictions:** none found between sources; no live comparison was made.
