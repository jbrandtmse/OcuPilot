## Leads

- `%CSP.UI.Portal.Mirror.Monitor` opens `%CSP.UI.Portal.Dialog.MirrorAuthorizedAsync.zen` (line 627-628), but no such class exists in the export (`Portal/Dialog/` holds only `DBMirrorAdd`, `MirrorDBActions`, `MirrorPromote`). Likely a `[ Hidden ]` class omitted by the Atelier document list — fetch it from the instance with `%Compiler.UDL.TextServices.GetTextAsString` before scoping the async-authorization feature.
- Two truncate implementations coexist: the full page `%CSP.UI.Portal.DatabaseTruncate` ("Cleanup", `/csp/sys/op/%CSP.UI.Portal.DatabaseTruncate.zen`) and the dialog `%CSP.UI.Portal.Background.Dialog.DatabaseTruncate`. Database Details only launches the dialog, so the page looks orphaned/legacy; confirm before counting it as a feature.
- The Backup run form (`UtilSysBackup.csp`) has JS `deletetask` and a hidden `DeleteTask` field, suggesting it creates a transient `%SYS.Task` to run the backup; the `.csp` source (not granted) or the `%SYS.Task` API should be read to decide whether an agentic replacement calls `Backup.General` directly or the task.
- `UtilSysBackupTasks.csp` (linked from every Backup page) and `UtilSysBackupLogs.csp` per-log viewer could not be exercised because the fresh container has no backup history; re-check after one backup.
- The Task Details "Edit" command targets legacy `UtilSysTaskOption.csp`, which rendered empty for every `$ID1` tried — it may require a POST or a session variable set by the schedule page; the Task Builder wizard field list (captured live) is the closest evidence for the edit form.
- `%CSP.UI.Portal.TasksOnDemand` and `TasksUpcoming` class comments say "System Administration - Task on demand" although the menu places them under System Operation; harmless, but do not classify by class comment.
- `Task1` ("Test task") is in the `TASKS` whitelist of `%CSP.UI.System.BackgroundTask`; ignore for parity.
- Chrome DevTools was not attempted (curl with basic auth was sufficient for confirmation); if a JS-rendered view of the Zen home-page finder is needed to confirm item ordering, that is still open.
