## 1. Issue summary

Two external facts landed after the plan was written.

1. **The admin API's status.** At the contest kick-off (2026-09-14) InterSystems named `/api/admin`
   **v2** as the API contestants should use: experimental, final in IRIS 2027.1, subject to change
   until then, the 2026.2 build being the contest version. On 2026-09-15 they published its spec
   (`intersystems-community/sysadmin-api-specification`, `mainspec_v2.json`, OpenAPI 3.0.0, 190
   paths). Verified against the instance the same day: 185 v2 paths on both sides, identical method
   sets on all 184 shared, no deprecations, v1 absent from the contract. Every planning sentence
   that calls the API "hidden, undocumented, unsupported, no stability contract" is now stale.
2. **The task statement names "OAuth setup" verbatim**, and the owner wants the tail of Release 1
   re-sequenced so a judge sees the OAuth editors and can run the agent on an OpenAI key before the
   09-24 release, with the plain-Community check run the moment the floor is built.

A third input rides along: the published spec was joined to the derived write-tool field lists
(AD-3): 38 PUT schemas comparable, 33 identical; the deltas are story-level notes below.
