Direction D — Beacon

The logo's gradient becomes the header, full bleed from navy at the wordmark to teal at the server flag, and every surface beneath it is a Material 3 tonal container tinted from that gradient instead of a bordered box. Robot yellow is spent generously — the agent's avatar, the proposal card's header, the active rail entry, the server flag, the changed row — so the agent co-pilot is visibly the loudest thing on the screen, which is the product's argument.

Shapes are round (16px cards, 18px bubbles, pill fields and buttons) and type is heavier (14px body, 700–800 headings), giving the portal a warm, contest-demo confidence rather than console austerity. Dark mode keeps the gradient header and swaps the tonal tints for their dark counterparts (see token comment), so the beacon still reads at night.
