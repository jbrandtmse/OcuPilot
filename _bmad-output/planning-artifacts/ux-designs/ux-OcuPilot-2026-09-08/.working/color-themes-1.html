OcuPilot color themes — round 1

Five variations of the bold and branded register, hues sampled from the logo (wordmark navy #103858, gradient #185478 → #2090A0 → #38A8B0, globe aqua #60D0B8, robot yellow #DEDE54, ground #E4F0F0). Each is expressed as Material 3 roles plus the OcuPilot roles, shown light and dark side by side with the same UJ-3 moment. Every ratio shown is computed; nothing below 4.5:1 for text or 3:1 for the focus ring survived into this file. Hex values for every role, with ratios, are in the <style> comment at the foot of the file.

navy from the wordmark teal from the gradient aqua from the globe yellow from the robot Chip label = role pair · hex of the fill · computed ratio of the text on it.

V1 · Deck

Navy chrome, teal as the action color

The wordmark navy owns the header and navigation; teal is reserved for buttons, links and selection so every actionable thing shares one hue. Reads like a bridge console: authoritative, low-glare, the closest in spirit to the classic portal's dark header.

  • Yellow is too light to be text on white, so light-mode agent-accent is the dark gold #6B5E00 (5.97:1 on its pale-yellow container); the robot yellow itself (#F2D64B) returns as the dark-mode accent.
  • Focus ring is a two-tone ring (navy outer + white inner in light, cyan outer + surface inner in dark) so it clears 3:1 against any adjacent color, including the teal primary button.

V2 · Iris

Teal-dominant chrome, navy text, yellow reserved for the agent

The globe's aqua-teal becomes the shell: header and surfaces carry a cool aqua tint, navy is the ink and the primary button. Yellow appears nowhere except where the agent speaks, so its meaning is unambiguous. Airy and clinical; suits long sessions in a bright room.

  • Mid-tone teal (#2090A0, straight from the logo) reaches 4.5:1 with neither black nor white, so the light header uses the lighter aqua #8FDCDF with navy text (10.05:1) instead of white-on-teal.
  • Dark-mode focus ring is the agent yellow deliberately: with yellow otherwise confined to the agent's cards, the ring is still unmistakable on the teal-black surfaces (11.74:1).

V3 · Lantern

Light neutral chrome; the gradient lives only in the header and the panel's edge

Surfaces are neutral white and gray, so the tables do the talking. The navy-to-teal gradient is confined to a slim header and the panel's docked edge, the way the logo's panel sits against the eye. Yellow marks the agent and, in this variation, also the just-changed row, tying "the agent did this" to one color.

  • change-highlight is the agent's pale yellow (#FFF3B8, 14.83:1 with row text) rather than aqua: the highlight means "changed by a confirmed agent write", so it borrows the agent's hue.
  • Text-bearing gradient stops end at #1C6A88 rather than the logo's brighter #2090A0, because white on #2090A0 is only 3.78:1; the brighter teal is kept for the non-text edge stripe.

V4 · Signal

High saturation; the navy-to-teal gradient is everywhere

Built for the demo recording and the contest screenshot: gradient header, gradient panel edge, aqua-tinted surfaces, saturated containers, and the robot yellow used as a solid fill on the agent's label. The ink is navy rather than gray-black, so even body text is on-brand. Loud by design; the most recognizable of the five at thumbnail size.

  • The logo's vivid teal #2090A0 fails as a button fill (white on it is 3.78:1); primary is pulled down to #08737F (5.57:1) and the vivid stop survives in the gradient behind non-text areas only.
  • The agent label is a solid pill here (agent-accent fill, on-agent-accent text). In light that fill is the dark gold #6F5F00 with white text (6.34:1), because white on any usable yellow fails AA; the vivid robot yellow becomes the solid fill only in dark mode.

Light mode is derived by inversion and stays cool and slightly dim (surface #E9EFF4, not white) so the two modes feel like one instrument with the lights up or down.
